# 만다라트

하나의 큰 목표를 8개의 핵심 목표와 64개의 실행 항목으로 나누는 브라우저 기반 만다라트 플래너입니다.

## 기능

- 9×9 만다라트 보드
- 중앙 핵심 목표와 외곽 보드 자동 연결
- 실행 항목 완료 체크 및 진행률
- 브라우저 자동 저장
- JSON 내보내기/불러오기
- 인쇄용 레이아웃
- 모바일 반응형 UI

## 실행

별도 설치나 빌드가 필요 없습니다. `dist/index.html`을 브라우저에서 열면 됩니다.

## 배포

GitHub Actions가 `dist/` 폴더를 GitHub Pages에 배포합니다.
